# 企微长连接媒体上传合同核验

核验日期：2026-10-20，UTC+8。依据[企业微信官方媒体文档](https://developer.work.weixin.qq.com/document/path/101463)的直接HTTPS正文、固定`@wecom/aibot-node-sdk@1.0.7`发布包的类型及实际CJS，不依据第三方实现推断协议。

| 接点 | 核实结果及本项目处理 |
| --- | --- |
| 流程 | 初始化取得upload_id，上传分片，完成后取得media_id，再发送文件消息；上传不是最终消息投递 |
| 分片序号 | 正文明确从0开始；现有CJS及本项目保持0、1…，无需改为1起 |
| 字段类型差异 | 文档表格将chunk_index列为string，但官方JSON示例与SDK类型/运行时均使用数字。本地保持数字，不将合成ACK当平台验证 |
| 分片尺寸 | 编码前每片最多512KB；沿用SDK的524288字节，每片单独Base64；最多100片，不发送空尾片 |
| 文件 | 最少5字节，普通文件上限20MB。复用原sender更保守的20,000,000字节上限；不扩大既有大小准入 |
| 文件名 | 按UTF-8字节不超过256校验，同时保留原255字符及字符集限制，不声称接受平台全部允许名称 |
| 完整性 | 初始化携带原文件字节的MD5、总字节数及分片数 |
| 回复归因 | 请求号关联ACK、校验错误码；上传会话与机器人绑定。每帧独立ID、顺序执行、不自动重试，取消后不准入下一帧 |
| 有效期 | 上传会话30分钟、临时素材3天；本轮不增加缓存/断线续传能力，不复用过期会话 |

SDK的d.ts注释写从1开始，与官方正文及该发布包CJS不一致，应以核实的正文解释起点。网页示例也不能替代约束，例如示例分片数超过正文上限时不能照抄。
