# T7 受控联调前装配计划

日期：2026-10-20，UTC+8。基线T6 `cd767c1aef057063948e1de786ab47bdf9523094`，分支`feat/wecom-assembly-t7`；T6 PR仍开放，本轮依赖T6提交，不直接合main。基线33文件428项通过。

本轮只推进T7的前置核验、最小装配和离线验证。员工操作及查回仍在企微，原业务/授权/账本/运行循环不重做；生产、真实连接/发送、模型、迁移和发布均未授权。真正手机联调和发布验收不能在本轮标记完成。

1. **核验外部和原服务契约。** 固定官方发布SDK版本及完整性，分别记录GitHub源码与npm发布包，不能将不相同版本混为同一源码。查真实事件名、认证/断连状态、回调字段、发送ACK/排队及上传重试。只读核验原Native数据库导出、调度回调/依赖及暂停门禁，不import或初始化原运行时、不读取真实数据和凭据。
2. **逐事件可信分发。** 新增仅本地合成模式的SDK装配边界：只订阅已给定SDK实例的特定消息/卡片事件，捕获当前认证会话与不可变帧；逐事件创建原T1授权及原delivery，不共享“当前员工”。绑定、账号/Home、门店、岗位与原员工映射均走已有服务。静态显式注入已有业务对象，不发现文件、不静默建空库。缺失单聊归因、未认证/断线/踢线、绑定和权限异常拒绝。
3. **生命周期与并发。** 装配不connect、不disconnect、不启动循环；认证成功才ready，掉线/重连/错误/关闭废止当前会话并取消在途请求。接收与发送前检查同一会话及预算，未知通知不自动重投；设有限在途容量，不建立无限队列。close只移除本装配监听和私有资源，不关闭调用方的原账本/SDK/后台培训服务。
4. **原Native最小只读服务桥。** 组合真实`getTaskById`、`getRegisteredGroup`、`getAgentProfile`、`getWorkspaceAgentProfileBinding(folder)`及`getTaskRunById`的合成原形返回，显式映射`executionMode`并只投影必要字段。快照沿用原函数已解析的对象，不双重JSON.parse。保留T5 Owner/Profile/非Home/run/key校验。执行端继续关闭，不裸注入会推进全库调度且无请求者ACL的`triggerTaskNow`，不临时构造schedulerDeps、不调用有默认Profile修复写入的读取函数。
5. **有效行为测试及场景。** 真实安装SDK仅作为精确固定的开发验证依赖；测试替换最低层传输，运行真实SDK分发、序列化和上传流程，不调用connect。测试实际临时SQLite/工件上的多成员报数→确认→查询、原Native读取桥及任务进度、并发/重复、断线晚到/重连、未映射/撤权/跨店、伪造和缺失单聊事件；测试资源所有权、有限容量和错误降级。新行为先有效RED再实现。
6. **审查和交付。** 专项后跑全量test/typecheck/build、原调用方兼容和相关演示，来源/依赖/敏感内容检查，固定版本独立规格与质量审查。README、roadmap和验收记录区分“实际包离线验证”“原服务只读投影”“待真实装配/执行/手机验收”。提交GitHub依赖PR，保留生产/发送/模型边界。

发送装配继续显式接收原`isolated-synthetic`发送端口；真实`WSClient`只作为事件契约类型/离线测试对象，不由生产源码自动转换成合成sender。当前SDK的排队回复/分片上传没有AbortSignal，队列中的发送可能晚于本地超时，真实出站必须继续阻断，不能用Promise.race声称取消。实际SDK序列化/上传验证只在最低层网络已替换的测试fixture中进行。

不采用本轮直接连接真实SDK/Native的方案，也不再造机器人业务执行器。真实服务写入回调、原暂停恢复、全库调度影响、SDK卡片事件单聊归因及不可取消的SDK上传等风险保留为后续联调条件；没有证据的契约不补猜测默认值。
