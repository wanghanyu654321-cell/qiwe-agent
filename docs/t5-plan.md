# T5 企微任务接入实施约定

日期：2026-10-18，UTC+8。基线T4 `70ae2d209c85b0b05d648afb0f19c514afde5c15`；开发分支`feat/wecom-tasks-t5`，依赖PR面向T4分支。用户已批准继续既定T5；本阶段不重新设计产品入口。

目标：复用原Agent任务和培训业务，员工在企微提交、查进度/结果及取消，重启后仍按原编号查回。仅本地合成端口、临时数据库及获准合成资料；不改生产、真实渠道、模型额度或Home岗位绑定。

## 已核实的契约与限制

- 当前Native主/子会话从工作区绑定解析Profile，没有按单条消息指定岗位Profile的入口；Home会强制默认Profile。不能通过换Home绑定或另开Agent循环模拟岗位切换。
- 原scheduler有现有任务的手动触发、持久run和精确run取消接缝。T5仅可承接服务端预先登记的已有非Home岗位工作区任务别名，要求显式is_home:0/false、当前Owner/Profile/绑定一致；不自动创建/改写定时任务、不把任意提示词伪装成原scheduler任务。Native默认暂停；未装配时明确block，合成端口不等于真实Native恢复。
- 原培训generation已有start/get/settled、requestKey/inputHash、引用校验、来源变化stale和重启running→unknown；没有cancel。精选复用此服务、原知识读取/输出合同及行为测试，补精确任务取消，取消后迟到输出不能改为ready。真实Pi worker、凭据、资料正文及私有运行循环不迁入。

## 逐项实施与验收

1. **原服务接缝。** 记录Native任务/岗位/培训实际签名、调用方和暂停门禁。培训原知识/输出模块原样复用；generation仅补取消、当前作用域和对象引用保护。行为先红后绿，保留原测试。
2. **任务引用持久化。** 新增明确配置的SQLite渠道任务引用表，记录可信账号/门店/Home/岗位/成员、原请求键/任务/run引用及确认收到的事实。它不是第二执行器或业务账本，没有调度循环。请求先预留再调用；触发后超时/崩溃为unknown，不自动重新执行。使用SQLite事务/唯一键验证同事件并发、调店重放及新进程查回。
3. **可信任务服务。** 复用T1当前授权，每条命令显式岗位。原Native执行/查询/取消由受控服务端端口负责Owner、原任务Profile与暂停/工具门禁；没有端口则不执行。培训调用原service，不调用模型。取消只针对已保存的精确原run或本进程培训任务，不调用宽泛stopGroup/interrupt工作区。
4. **企微指令与结果。** `执行任务 岗位 已有任务别名`、`培训问答/培训教案 身份 问题`、`查询任务 岗位 编号`、`取消任务 岗位 编号`。岗位由原授权验证，别名由服务端配置；查回含状态、原引用、输出或失败处理方式。复用T3回复outbox与发送器，不让查询ACK覆盖任务执行事实；员工无需跳Web。T2–T4命令保留原调用路径。
5. **集成与交付。** 撤权/跨店/账号绑定/Home变化、未知/重复/取消竞态、来源失效、错误引用和合成资料隔离场景；原培训及报数/文件兼容测试；独立进程演示。完整test/typecheck/build、适用回归、来源及敏感内容检查后独立规格/质量审查，推送依赖PR，不直接合main。

执行与消息确认、取消请求受理与原运行终态分别记录。无法核实的原任务状态明确unknown；没有返回原runId不能宣称已运行。真实Native装配、资格/暂停恢复、模型与手机验收留待后续具体授权。
